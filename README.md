# מחברת אנטומיה — גרסה לפרסום

האתר כולל שישה עמודים נפרדים ונכסים משותפים. פתיחת שיעור טוענת רק אותו.
הערות והתקדמות נשמרות בדפדפן ובכתובת האתר הנוכחיים. אין סנכרון בין מכשירים.
למעבר מהקובץ המקומי לאתר: ייצאו גיבוי במחברת הישנה וייבאו אותו במחברת שבאתר.

פרסום ב־GitHub Pages:
1. צרו מאגר GitHub חדש והעלו אליו את כל תוכן התיקייה הזו, כולל lessons ו-assets. index.html צריך להיות בשורש המאגר.
2. פתחו Settings → Pages → Build and deployment → Deploy from a branch.
3. בחרו main ואת / (root), ושמרו. GitHub יציג קישור לאחר השלמת הפרסום.
4. לעדכונים בהמשך, החליפו קבצים באותו מאגר; כתובת האתר תישאר קבועה.

בדיקה מקומית: python3 -m http.server 8000 ואז פתחו http://localhost:8000.
פתיחה ישירה של index.html מתוך ZIP אינה תחליף לשרת.
מקורות, ייחוס ורישיונות המודלים נשמרו בשיעורים המתאימים.
