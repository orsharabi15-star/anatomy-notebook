# Knowbody Concept Page Generator

גנרטור אוטומטי לדפי מושג Knowbody מקבצי markdown.

## מבנה

```
scripts/generator/
├── generate_concept.py   # הגנרטור הראשי
├── gold_test.py          # בדיקת זהב (השוואה לדפים חיים)
└── README.md             # התיעוד הזה

concepts/shared/
├── knowbody-concept.css  # CSS משותף לכל הדפים
└── knowbody-concept.js   # JavaScript משותף (תפריט נייד)
```

## שימוש

### יצירת דף מושג חדש

```bash
python3 scripts/generator/generate_concept.py <source.md> <output.html>
```

דוגמה:
```bash
python3 scripts/generator/generate_concept.py \
  /path/to/infraspinatus.md \
  concepts/infraspinatus.html
```

### בדיקות אוטומטיות

הגנרטור מבצע אימות לפני הייצור:
- ✅ כל השדות הנדרשים קיימים
- ✅ הצבע מהפלטה הנעולה
- ✅ קובץ האיור קיים בתיקייה
- ✅ בדיוק 3 שאלות בבוחן
- ✅ אין סודות בטקסט
- ✅ אין קישורים מומצאים בשמות חפיסות

אם הבדיקה נכשלת, הקובץ לא נוצר.

### הרצת בדיקת זהב

```bash
python3 scripts/generator/gold_test.py
```

**הערה**: בדיקת הזהב על supraspinatus תיכשל במכוון. הסיבות:

1. **תשובות בוחן**: הדף החי מכיל תשובות מפורטות שנכתבו ידנית (למשל: "עצב על-שכמי, C5-C6"). קובץ ה-MD המקורי לא כלל תשובות בסעיף 6 - רק שאלות. הגנרטור המתוקן דורש תשובות בקובץ המקור, ואם אין - האימות נכשל.

2. **איור SVG מותאם אישית**: הדף החי משתמש ב-SVG inline מפורט שנוצר ידנית. הגנרטור משתמש בקובץ PNG מ-assets/knowbody-atlas/.

3. **תוכן מורחב**: הדף החי כולל הערות פיילוט, פרטי חפיסות (מספרי כרטיסים), ומידע נוסף שלא בקובץ ה-MD הפשוט.

**מסקנה**: הגנרטור מיועד ליצור דפים **חדשים** מקבצי MD מפורטים (כולל תשובות בבוחן), לא לשכפל את הדף הפיילוט המקורי שנבנה ידנית בסיבוב הראשון.

## פורמט קובץ המקור

קובץ ה-MD צריך לכלול:

```markdown
# שם עברי - Latin Name

## 1. זיהוי
- שם עברי: ...
- שם לטיני: ...
- צבע המבנה: ... #XXXXXX
- סטטוס אימות: ...

## 2. תקציר - 2 משפטים
...

## 3. טבלת עובדות מפתח - OIAI
- מוצא: ...
- אחז: ...
- עצבוב: ...
- פעולה: ...
- אספקת דם: ... (אופציונלי)

## 4. משמעות קלינית - תיבה נפרדת
...

## 5. איור
- קובץ איור מדויק: 05_illustrations/filename.png
- תיאור האיור הרצוי במשפט אחד: ...

## 6. למידה אקטיבית - בוחן / תוויות נסתרות
1. שאלה ראשונה?
   תשובה לשאלה הראשונה.

2. שאלה שנייה?
   תשובה לשאלה השנייה.

3. שאלה שלישית?
   תשובה לשאלה השלישית.

## 7. חפיסות קשורות - שמות בלבד
- שם חפיסה 1
- שם חפיסה 2
- שם חפיסה 3
```

## CSS/JS משותפים

הגנרטור קורא את הקבצים המשותפים ומטמיע אותם **inline** בדף הנוצר.
כך:
1. יש מקור אמת יחיד לעיצוב (concepts/shared/)
2. הדפים הנוצרים עצמאיים לחלוטין (inline CSS/JS)
3. אין תלות בקבצים חיצוניים

## מה הגנרטור לא עושה

- ❌ אינו משנה דפים קיימים
- ❌ אינו יוצר SVG inline מותאם אישית
- ❌ אינו מוסיף תוכן שלא בקובץ ה-MD
- ❌ אינו ממציא קישורים או חפיסות

## סטטוס בדיקת הזהב

בדיקת הזהב (`gold_test.py`) משווה את פלט הגנרטור לדף החי `concepts/supraspinatus.html`.

**סטטוס נוכחי**: הבדיקה נכשלת באימות (validation failure) כי קובץ ה-MD המקורי `supraspinatus.md` לא כולל תשובות בסעיף הבוחן. זה התנהגות צפויה ונכונה.

**כדי שהבדיקה תעבור**: יש להוסיף תשובות מפורטות לקובץ `supraspinatus.md` בסעיף 6, בפורמט:
```markdown
## 6. למידה אקטיבית - בוחן / תוויות נסתרות
1. שאלה ראשונה?
   תשובה מפורטת כאן.

2. שאלה שנייה?
   תשובה מפורטת כאן.
```

גם אז, הבדיקה לא תעבור זהה לחלוטין בגלל הבדלי SVG ותוכן מורחב, אבל לפחות תוכל לעבור את שלב האימות ולהשוות HTML.
